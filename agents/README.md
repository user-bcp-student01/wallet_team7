# Agentes

Coloca aqui las definiciones y la configuracion de agentes del proyecto.

## Ubicacion de entregables

La raiz del proyecto es `wallet_team7`, el directorio que contiene `agents/`, `src/`,
`docs/` y `tests/`. Todos los agentes deben tomar esa carpeta como raiz de trabajo y
guardar los archivos que generen dentro de ella; no deben escribir en el directorio
`agents/`, en un directorio hermano ni fuera de `wallet_team7`.

Los informes y especificaciones independientes se guardan directamente en la raiz del
proyecto. Si un flujo exige una estructura canonica, como `openspec/changes/`, esta debe
crearse y mantenerse dentro de `wallet_team7`.
